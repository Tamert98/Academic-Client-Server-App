# Academic Client-Server Application

## Overview

This project was developed as part of a Software Engineering course.

It is a multi-user client-server application designed to manage structured workflows between different user roles. The project focuses on client-server communication, database integration, application logic, role-based access, and desktop GUI development.

## Demo

<img src="https://github.com/Tamert98/Academic-Client-Server-App/blob/main/demo-git.gif" width="600" height="375"/>

## Main Features

- Role-based access for multiple user types
- Structured data creation and management
- Submission and evaluation workflows
- Automatic and manual result processing
- Statistical analysis and reporting
- Administrative monitoring and control
- Client-server communication and message handling
- Persistent data storage using MySQL

## Technologies Used

- Java
- JavaFX
- FXML
- CSS
- MySQL
- OCSF Client-Server Framework
- Git / GitHub

## Architecture

The application follows a client-server architecture.

The client side provides the graphical user interface and communicates with the server through the OCSF framework. The server processes requests, manages application logic, and interacts with the MySQL database.
